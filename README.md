# Медиатека Lite — iPad mini 2 Retina

Нативное UIKit-приложение iOS 10–12: каталог, поиск, Мой список и офлайн-видео с постерами. Без КиноВайба и премьер.

## Версия 0.1.2, сборка 4

- В «Загрузках» карточка появляется сразу после выбора источника: постановка в очередь, подготовка MP4 на сервере, скачивание с процентами и объёмом, проверка и готовность офлайн.
- Подготовкой управляет хранилище, поэтому переход между вкладками её не отменяет. Сохранённое задание возобновляет опрос после следующего входа; паузу можно продолжить вручную. Во время сворачивания опрос ждёт возврата в приложение, начавшееся скачивание использует фоновый URLSession.
- Каталог: «Фильмы» / «Сериалы» и «Новые» / «Популярные», на существующих серверных подборках с пагинацией.
- Прежние локальные файлы, постеры, учётная запись и путь хранения сохранены.

Источник `mediateka-ipad746-source.zip`, папка `MediatekaLite`. SHA256: `93c1583a6f5a983fbd08c09644d34d75fd8e543bb1707f46f84d0e8d47667b59`.

AppVeyor macos-monterey / Xcode 13.4.1 компилирует проект и выполняет 43 модельные проверки.
`MediatekaLite-0.1.2-ios10-AppSync-build4.ipa` — ad-hoc подпись с application-identifier и SHA1+SHA256; для активного джейлбрейка с AppSync. Отдельный unsigned IPA требует подписи.

Исходники не содержат ключей Apple, provisioning-профилей, серверных секретов или пользовательских данных. HTTPS-проверка сохранена. Изменение не требует обновления сервера, PWA или Android APK.

До получения успешного результата CI сборка считается подготовленной. Проверка на физическом iPad выполняется отдельно.
