# Медиатека Lite — iPad mini 2 Retina

Нативное UIKit-приложение iOS 10–12: каталог, поиск, Мой список и офлайн-видео с постерами. Без КиноВайба и премьер.

## Версия 0.1.3, сборка 5

- На iPad mini 2 разрешение ограничено 720p (1280×720) в подборе, просмотре и загрузках; клиент запрашивает такой же предел на сервере.
- Первая вкладка — «Главная» с собственным значком дома, без системной надписи «Избранное».
- Для неудавшейся загрузки доступен выбор другой раздачи.
- В «Загрузках» карточка появляется сразу после выбора источника: постановка в очередь, подготовка MP4 на сервере, скачивание с процентами и объёмом, проверка и готовность офлайн.
- Подготовкой управляет хранилище, поэтому переход между вкладками её не отменяет. Сохранённое задание возобновляет опрос после следующего входа; паузу можно продолжить вручную. Во время сворачивания опрос ждёт возврата в приложение, начавшееся скачивание использует фоновый URLSession.
- Каталог: «Фильмы» / «Сериалы» и «Новые» / «Популярные», на существующих серверных подборках с пагинацией.
- Прежние локальные файлы, постеры, учётная запись и путь хранения сохранены.

Источник `mediateka-ipad747-source.zip`, папка `MediatekaLite`. SHA256: `3c5eafbd77b521306218b1e98acb6dcc001f7b498b8e1182d958d584b1323882`.

AppVeyor macos-monterey / Xcode 13.4.1 компилирует проект и выполняет 63 модельные проверки.
`MediatekaLite-0.1.3-ios10-AppSync-build5.ipa` — ad-hoc подпись с application-identifier и SHA1+SHA256; для активного джейлбрейка с AppSync. Отдельный unsigned IPA требует подписи.

Исходники не содержат ключей Apple, provisioning-профилей, серверных секретов или пользовательских данных. HTTPS-проверка сохранена. Серверный ограничитель качества дополнен отдельным пределом 720p для Lite-клиента; PWA и Android APK сохраняют прежние ограничения.

До получения успешного результата CI сборка считается подготовленной. Проверка на физическом iPad выполняется отдельно.
