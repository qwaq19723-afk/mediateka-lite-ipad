# Медиатека Lite — iPad mini 2 Retina

Нативное приложение UIKit для iOS 10–12: каталог, поиск, Мой список и настоящее офлайн-видео.
Первым открывается Офлайн с локальными постерами. КиноВайб и премьеры исключены.

**Статус: исходники подготовлены. Совместимость не подтверждена до успешной сборки и проверки на iPad.**

Полный исходный проект находится в `mediateka-ipad740-source.zip`, папка `MediatekaLite`.
Архив включает Swift-исходники, Xcode-проект, ресурсы, README_RU и проверки.
AppVeyor проверяет SHA256 и распаковывает его перед сборкой Xcode13.4.1 в macos-monterey.
Результат — неподписанная IPA; для установки необходима отдельная подпись Apple.
Ключи, сессионные cookies и персональная медиатека в репозиторий не входят.
