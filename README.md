# Медиатека Lite — iPad mini 2 Retina

Нативное UIKit-приложение iOS 10–12: каталог, поиск, Мой список и офлайн-видео с постерами. Без КиноВайба и премьер.

## Сборка 3 — подключение и вход

Исправлены заголовки создания кода Telegram-входа. Ответ сервера «нужен вход» теперь отличается от отсутствия связи; добавлены явные сообщения и кнопки «Войти» / «Проверить связь». Офлайн открывается до сетевого запроса и остаётся доступным без сети.

Источник `mediateka-ipad744-source.zip`, папка `MediatekaLite`. SHA256: `7a7f5d8ce6ec6f8ba8aa81a4c101769c4e2dc81e5b7c317869c20b2b0811a9fd`.

AppVeyor macos-monterey / Xcode 13.4.1 компилирует проект и запускает 22 модельные проверки. Создаёт два отдельных IPA:

- `MediatekaLite-0.1.1-ios10-AppSync-build3.ipa`: локальная ad-hoc подпись с application-identifier и SHA1+SHA256; только для активного джейлбрейка с AppSync.
- `MediatekaLite-0.1-ios10-unsigned.ipa`: без подписи, требует отдельной подписи перед установкой.

Ключи Apple, provisioning-профили, серверные секреты и пользовательские данные отсутствуют. Проверка сертификатов HTTPS сохранена. Серверные правила входа не изменяются.

Предыдущая сборка 2 установлена и открывается на пользовательском iPad; подтверждён дефект входа. Сборка 3 требует успешной компиляции и проверки входа на устройстве.
