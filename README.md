# Медиатека Lite — iPad mini 2 Retina

Нативный UIKit-клиент iOS10–12, arm64. Главная, поиск, закладки и офлайн-видео с постерами. Без КиноВайба и премьер.

## Версия0.1.5, сборка7

- Две параллельные загрузки с учётом свободного места и объёма остальных заданий. Подготовка серверных файлов остаётся последовательной.
- После проверки MP4/H.264/AAC, SHA256 и сохранения локального индекса приложение подтверждает скачивание серверу. Сервер освобождает временную копию, не затрагивая локальный файл. Неотправленные квитанции сохраняются и повторяются после возврата сети/входа своего владельца. Старые скачивания без квитанций обслуживает прежняя серверная TTL-очистка.
- Короткое нажатие готовой карточки сразу запускает офлайн-просмотр. Удержание0,65сек открывает меню с удалением. Короткое нажатие незавершённого файла открывает управление без удаления.
- При скачивании список раздач проверяется до выбора исходника. Среди подходящих720p/H.264 приоритет получают компактные варианты с подтверждёнными сидами; мёртвые источники по размеру не выигрывают. Размер и сиды видны в примечаниях.
- В карточке загрузки отображаются текущая скорость и примерное оставшееся время.
- «Добавить в закладки» и отдельный список закладок, обновляемый при каждом открытии.

Предел1280x720 сохранён. Начавшиеся передачи используют backgroundURLSession; для подготовки следующих файлов и повторов квитанций держите приложение открытым. Сервер не изменяется и не перезапускается. Существующий путь хранения, вход, файлы и постеры сохраняются.

Источник `mediateka-ipad757-source.zip`, папка `MediatekaLite`. SHA256: `8c1d8f092a45405355fcdc793a3568f833b0ee42b86367cf44f1887396895118`.

AppVeyor/Xcode13.4.1 компилирует проект и выполняет 131 проверок моделей и контрольных сумм. Успех подтверждается только результатом CI. Физический iPad отдельно не проверен.

Для установки AppSyncIPA нужен активный джейлбрейк и AppSyncUnified. Устанавливайте поверх прежнего приложения, не удаляя его. Это локальная ad-hoc подпись, не AppleDeveloper.

**Перед установкой дождитесь завершения текущих скачиваний на iPad:** установщик заменяет приложение и может завершить его процесс. Серверные скачивания в ходе разработки не останавливаются.

В исходниках нет ключей Apple, provisioning-профилей, серверных секретов и пользовательских данных. HTTPS-проверка сохранена.
