# Медиатека Lite — iPad mini2

Медиатека Lite 0.1.6, build8, iPad mini2 iOS10–12.
Постеры: до трёх сетевых запросов одновременно, объединение одинаковых запросов,
две повторные попытки после временных ошибок; тайм-аут30сек, изображения до8МБ,
уменьшение до600px. Офлайн-постеры повторно загружаются при открытии загрузок
и возврате сети. Сохранённый постер остаётся при ошибках.
Хранилище: прежний Offline740; резервный индекс, отдельные записи загрузок,
дополнительная локальная запись последнего владельца. При повреждении индекса
восстановление из резервных записей своего владельца. Если восстановить нельзя,
запись пустого списка блокируется, файлы сохраняются и показывается сообщение.
Удалённые вручную записи не восстанавливаются из старого индекса.
Это не восстанавливает уже удалённый установщиком контейнер/файлы и не гарантирует
восстановление старого повреждённого индекса без резервных записей.
Перед обновлением дождитесь окончания скачиваний. Не удаляйте старое приложение.
Сервер и активные скачивания разработкой не останавливаются.
